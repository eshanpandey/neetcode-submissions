# NeetCode 150 solutions

My solutions to the [NeetCode 150](https://neetcode.io/practice) interview problem list, synced automatically from NeetCode.io. I mostly write Java, with some Python.

## How it's organised

```
Data Structures & Algorithms/<problem>/submission-N.<java|py>
Design Patterns/<pattern>/submission-N.java
```

Each folder holds one problem; extra `submission-N` files are alternative or improved attempts.

## Topics covered so far

Arrays and hashing, two pointers, trees, graphs (BFS/DFS, grids), heaps and top-K, plus object-oriented design patterns (factory, prototype).

## Approach

For every problem I first write the brute force, then improve it and note the time and space complexity. I'm working through the list topic by topic and revisiting weak areas such as graphs.
